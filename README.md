# ALICE
### ALICE's Limited Interactive Computing Environment

**How deep does your rabbit hole go?** 🐇

ALICE is an open-source, self-hosted workbench designed for humans and AI agents to interact with applications, development environments, and remote systems through a shared interface.

Unlike traditional AI coding assistants, ALICE isn't tied to an IDE. Instead, it provides isolated, project-based environments where agents can interact with browsers, terminals, graphical applications, virtual machines, and other resources using virtual keyboard and mouse input or native tool interfaces.

### Core Principles

- **Open Source First:** Built on open-source technologies, without proprietary dependencies.
- **Self-Hosted:** Your infrastructure, your models, your data.
- **Agent Agnostic:** Compatible with different LLMs and agent frameworks.
- **Security by Design:** Project-scoped permissions enforced by the system, not AI prompts.
- **Human + AI Collaboration:** Humans and agents can observe, interact with, and share control of the same environments.
- **Modular Architecture:** A native C++ core with interchangeable frontends and extensible capabilities.
